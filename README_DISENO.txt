REDISEÑO FITNESS INDEPENDIENTE

Se actualizó el diseño visual a una interfaz oscura de gimnasio con acentos verde lima:
- Pantalla de acceso y registro con tarjetas oscuras, botón lima y opción de huella.
- Inicio con encabezado, panel destacado para iniciar entrenamiento y tarjetas de rutinas.
- Navegación inferior Inicio / Entrenar / Perfil.
- Perfil con ajuste para activar o desactivar inicio de sesión biométrico.
- Panel de actividad con tarjetas para pasos, distancia, duración e intensidad.
- Sensores, GPS/mapa e historial conservan sus funcionalidades y se presentan con el nuevo estilo.

Para abrir: descomprime, abre la carpeta del proyecto en Android Studio y ejecuta Flutter Pub Get.
En terminal:
flutter clean
flutter pub get
flutter analyze

Nota: el proyecto no se compiló aquí porque este entorno no tiene Flutter/Dart instalado. Verifica la compilación en Android Studio y reporta cualquier error de Build/Run.

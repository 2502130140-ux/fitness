FITNESS INDEPENDIENTE - Proyecto separado de SICA

Abrir esta carpeta en Android Studio (la carpeta que contiene pubspec.yaml).
En Terminal ejecutar:
  flutter pub get
  flutter run

Primero crea una cuenta. Para habilitar huella, inicia sesión y activa el switch de huella en el dashboard. La autenticación biométrica requiere huella registrada y bloqueo seguro configurado en el teléfono.

El botón de entrenamiento abre el panel de sensores (podómetro, acelerómetro, giroscopio, GPS, mapa e historial). Acepta permisos cuando se soliciten y activa ubicación del dispositivo.
